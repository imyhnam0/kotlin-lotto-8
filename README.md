# kotlin-lotto-precourse
# 🎰 로또 미션 (Lotto Mission)

---

## 🚀 과제 개요

간단한 **로또 발매기**를 구현한다.

- 1~45 범위의 중복되지 않는 6개의 번호를 가진 로또를 발행한다.
- 사용자가 입력한 구입 금액만큼 로또를 구매하고,
당첨 번호 및 보너스 번호를 비교하여 등수와 수익률을 계산한다.

---

## 🧩 기능 목록

### 1️⃣ 입력 기능

- [x]  로또 구입 금액을 입력받는다.
    - [x]  금액이 1,000원 단위인지 검증한다.
    - [x]  1,000원 미만이거나 1,000원으로 나누어떨어지지 않으면 예외 처리한다.
- [x]  당첨 번호 6개를 입력받는다.
    - [x]  쉼표(,) 기준으로 구분하여 숫자 리스트로 변환한다.
    - [x]  1~45 범위를 벗어나거나 중복된 번호가 있으면 예외 처리한다.
- [x]  보너스 번호를 입력받는다.
    - [x]  보너스 번호가 당첨 번호와 중복되지 않도록 검증한다.
    - [x]  1~45 범위를 벗어나면 예외 처리한다.

---

### 2️⃣ 로또 발행 기능

- [x]  구입 금액에 따라 구매 가능한 로또 개수를 계산한다.
- [x]  로또 1장의 가격은 1,000원이다.
- [x]  각 로또는 1~45 범위의 중복되지 않은 6개의 번호를 가진다.
- [x]  로또 번호는 오름차순으로 정렬하여 저장한다.
- [x]  발행한 로또 목록을 출력한다.

---

### 3️⃣ 당첨 결과 기능

- [x]  사용자가 구매한 로또 번호와 당첨 번호를 비교한다.
- [x]  일치하는 번호의 개수를 계산한다.
- [x]  보너스 번호 일치 여부를 판단한다.
- [x]  일치 개수 및 보너스 여부에 따라 등수를 계산한다.

| 등수 | 조건 | 상금 |
| --- | --- | --- |
| 1등 | 6개 번호 일치 | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원 |
| 3등 | 5개 번호 일치 | 1,500,000원 |
| 4등 | 4개 번호 일치 | 50,000원 |
| 5등 | 3개 번호 일치 | 5,000원 |

---

### 4️⃣ 결과 출력 기능

- [x]  각 등수별 당첨 개수를 출력한다.
- [x]  총 수익률을 계산한다.
    - [x]  수익률 = (총 상금 / 구입 금액) × 100
    - [x]  소수점 둘째 자리에서 반올림한다.
- [x]  “총 수익률은 62.5%입니다.” 형식으로 출력한다.

---

### 5️⃣ 예외 처리

- [x]  모든 입력값 검증 실패 시 `IllegalArgumentException`을 발생시킨다.
- [x]  에러 메시지는 반드시 `[ERROR]`로 시작해야 한다.
- [x]  예외 발생 시 프로그램이 종료되지 않고 해당 입력부터 다시 받는다.
